# ToDoList – React

A simple and interactive To-Do List application built with React. This project allows users to manage their daily tasks with an intuitive interface and basic task management features.

## Learning Objectives

This project was developed as a practical exercise to explore React fundamentals, including:

- React Hooks:
  - useState – Managing component state.
  - useEffect – Handling side effects, such as automatically focusing the input field.
  - useRef – Accessing and interacting with DOM elements.
- Functional components and props.
- Component-based architecture.
- Rendering lists dynamically.
- Updating arrays immutably.
- Handling user events and form submissions.
- Using unique keys when rendering lists.
- Styling components with CSS Modules.

## Features

- Add tasks – Create new tasks using the input form.
- Complete tasks – Mark tasks as completed or active.
- Edit tasks – Modify existing task descriptions.
- Delete tasks – Remove tasks from the list.
- Local Storage saves
